# Hello World

A simple "Hello, World!" program is a traditional first program for beginners learning a new programming language.

## Python

```python
print("Hello, World!")
```

## JavaScript (Node.js)

```javascript
console.log("Hello, World!");
```

## C

```c
#include <stdio.h>

int main() {
    printf("Hello, World!\n");
    return 0;
}
```

## Bash

```bash
echo "Hello, World!"
```
